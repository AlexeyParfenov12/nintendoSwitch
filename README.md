# Nintendo Switch CSS Art

Учебный CSS-проект: детализированная отрисовка Nintendo Switch средствами HTML и CSS.

## Что демонстрирует проект

- работу с абсолютным позиционированием;
- `border-radius`, `box-shadow`, `linear-gradient`, `radial-gradient`;
- `clip-path` и blur-эффекты;
- использование относительных единиц и `aspect-ratio`;
- построение сложной формы без Canvas и SVG.

## Статус

Готовый CSS-эксперимент. Проект сделан как демонстрация навыков вёрстки и работы с CSS-графикой.

## Технологии

HTML, CSS
